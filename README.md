# Chamomile Salon Website

Human-designed static demo landing page for Chamomile Salon in Al Qirawan, Riyadh.

## Demo notes
- No backend or database is required for this version.
- Appointment CTAs point to the salon's current online booking page.
- Service prices are intentionally shown as `N/A` until the client supplies and approves the official menu.
- Demo photography and copy should be replaced with client-approved assets/content before production launch.

## Stack
Plain semantic HTML, CSS and JavaScript. No framework or build step is required.
